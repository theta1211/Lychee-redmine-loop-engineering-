# 画面仕様

対象は3画面：①キュー一覧画面（トップ）②チケット詳細／ログ画面③設定画面。
すべてWindows統合認証を前提とし、ログイン画面は用意しない（未認証アクセスはIISが401を返す）。

## 1. キュー一覧画面（トップ）

### 目的
チケットの登録・実行順序の並べ替え・状態確認・キュー全体の一時停止／再開・強制中断を行う。

### レイアウト（イメージ）
```
┌──────────────────────────────────────────────────────────┐
│ Redmine自動開発ループ            [キューを一時停止する]      │
├──────────────────────────────────────────────────────────┤
│ ＋チケットを追加   番号:[____] 実装AI:[default v] レビューAI:[default v] [追加] │
├──────────────────────────────────────────────────────────┤
│ ▲▼│番号 │タイトル      │状態      │実装AI│レビューAI│登録者 │登録日時 │操作 │
│ 1 │#1234│○○機能の追加  │待機中     │gpt-4o│gpt-4o    │佐藤   │09/15 18:00│[削除]│
│ 2 │#1235│△△バグ修正    │実行中     │gpt-4o│claude    │鈴木   │09/15 18:05│[中断]│
│ 3 │#1236│□□改善       │要確認(人対応)│gpt-4o│gpt-4o  │佐藤   │09/14 19:00│[詳細]│
└──────────────────────────────────────────────────────────┘
```

### 表示項目
| 項目 | 内容 |
|---|---|
| 実行順序 | ドラッグ&ドロップで並べ替え可能（`waiting`状態の行のみ移動可） |
| チケット番号 | Redmine上のチケットへのリンク（新規タブ） |
| タイトル | Redmineから取得したチケット件名（取得失敗時は「取得失敗」と表示） |
| 状態 | 待機中／実行中／要確認（人対応）／完了（プッシュ済み）／中断済み |
| 実装AI／レビューAI | 個別指定時はモデル名、未指定時は「default（実際のデフォルト値）」と表示 |
| 登録者 | Windows認証のユーザー名 |
| 登録日時 | 登録日時 |
| 操作 | 状態に応じて「削除」（waitingのみ）／「中断」（runningのみ）／「詳細」（常時） |

### 操作
- **チケット追加**：チケット番号（必須）、実装AI／レビューAI（任意、未指定はデフォルト）を入力し追加。番号の重複（同一チケットが`waiting`/`running`で既に存在）はエラーとして登録を拒否する。
- **並べ替え**：ドラッグ&ドロップで`waiting`状態のチケットの順序のみ変更可能（`running`より前には並べ替え不可）。
- **キュー全体の一時停止／再開**：画面右上のトグルボタン。一時停止中はバナー表示（例：「キューは一時停止中です」）。
- **強制中断**：`running`状態の行にのみ表示。押下時に確認ダイアログを出す。
- **削除**：`waiting`状態の行にのみ表示。押下時に確認ダイアログを出す。

### 状態と表示色（提案）
| 状態 | 表示色 |
|---|---|
| 待機中 (waiting) | グレー |
| 実行中 (running) | 青 |
| 要確認・人対応 (needs_human) | 赤 |
| 完了・プッシュ済み (pushed) | 緑 |
| 中断済み (canceled) | オレンジ |

## 2. チケット詳細／ログ画面

### 目的
特定チケットの実行ログ（実装・レビュー・差し戻し・エラー・中断の履歴）を時系列で確認する。

### レイアウト（イメージ）
```
┌──────────────────────────────────────────────────────────┐
│ ← 一覧に戻る    #1235 △△バグ修正   状態: 実行中              │
├──────────────────────────────────────────────────────────┤
│ 18:05:01 [実装]  実装AIによる差分作成を開始…                  │
│ 18:07:30 [レビュー] RESULT: FAIL - ○○の考慮漏れがあります      │
│ 18:07:31 [差し戻し] retryCount=1/3、指摘内容を実装AIへ渡します  │
│ 18:09:10 [実装]  修正差分を作成…                              │
│ 18:10:40 [レビュー] RESULT: PASS                              │
│ 18:10:41 [プッシュ] ticket/1235 を origin へ push しました      │
└──────────────────────────────────────────────────────────┘
```

### 表示項目
| 項目 | 内容 |
|---|---|
| ヘッダ | チケット番号・タイトル・現在の状態・ブランチ名 |
| ログ一覧 | 時刻／フェーズ（実装／レビュー／差し戻し／プッシュ／エラー／中断）／内容（AIの出力やシステムメッセージ） |

### 操作
- `running`状態の場合のみ「強制中断」ボタンを表示（一覧画面と同じ挙動）。
- ログは`logs/{チケットID}.json`から取得し、追記順に表示する。

## 3. 設定画面

### 目的
デフォルトAIモデル・再実装上限回数など、`settings.json`の内容を確認・変更する。

### レイアウト（イメージ）
```
┌──────────────────────────────────────────────────────────┐
│ 設定                                                        │
├──────────────────────────────────────────────────────────┤
│ デフォルト実装AIモデル   [gpt-4o        v]                    │
│ デフォルトレビューAIモデル [gpt-4o        v]                    │
│ 再実装ループの上限回数    [3   ]回                             │
│                                              [保存]          │
├──────────────────────────────────────────────────────────┤
│ 参考情報（設定ファイルで管理・本画面からは変更不可）              │
│  Redmine URL: https://redmine.example.com                   │
│  対象リポジトリ: C:\repos\target-app                          │
└──────────────────────────────────────────────────────────┘
```

### 表示・編集項目
| 項目 | 編集可否 | 保存先 |
|---|---|---|
| デフォルト実装AIモデル | 可 | `settings.json` |
| デフォルトレビューAIモデル | 可 | `settings.json` |
| 再実装ループの上限回数 | 可（1以上の整数） | `settings.json` |
| Redmine URL／対象リポジトリパス | 不可（参照表示のみ） | `config/config.json`（機微情報のため画面からの編集は不可） |

### 入力チェック
- 再実装ループの上限回数：1以上の整数のみ許可。
- AIモデル：GitHub Copilot CLIが対応するモデル一覧から選択（自由入力は不可）。
