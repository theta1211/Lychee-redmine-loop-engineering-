# 画面仕様

対象は3画面：①キュー／履歴一覧画面（トップ）②チケット詳細／ログ画面③設定画面。
すべてWindows統合認証を前提とし、ログイン画面は用意しない（未認証アクセスはIISが401を返す）。
操作権限は利用者間で区別せず、誰でも全チケットを操作できる（要件定義のスコープどおり）。

## 1. キュー／履歴一覧画面（トップ）

### 目的
チケットの登録・実行順序の並べ替え・状態確認・キュー全体の一時停止／再開・強制中断・削除を行う。
稼働中のチケット（`waiting`/`running`）と終了済みのチケット（`pushed`/`needs_human`/`canceled`）はタブで分離する。

### レイアウト（イメージ）
```
┌──────────────────────────────────────────────────────────────┐
│ Redmine自動開発ループ                    [キューを一時停止する]    │
├──────────────────────────────────────────────────────────────┤
│ ＋チケットを追加  番号:[____] 実装AI:[default v] レビューAI:[default v] [追加] │
├──────────────────────────────────────────────────────────────┤
│ 【キュー】 │ 履歴                                                │
├──────────────────────────────────────────────────────────────┤
│ ▲▼│番号 │タイトル    │状態       │実装AI│レビューAI│登録者     │操作      │
│ 1 │#1234│○○機能の追加│待機中      │gpt-4o│gpt-4o  │DOMAIN\sato│[削除]    │
│ 2 │#1235│△△バグ修正  │実行中(2/3) │gpt-4o│claude  │DOMAIN\suzuki│[中断][詳細]│
└──────────────────────────────────────────────────────────────┘
        ↓「履歴」タブ
┌──────────────────────────────────────────────────────────────┐
│ キュー │ 【履歴】                                                │
├──────────────────────────────────────────────────────────────┤
│ 番号 │タイトル    │状態           │ブランチ       │終了日時    │操作      │
│#1230│□□改善     │完了(プッシュ済) │ticket/1230   │09/14 21:30│[詳細][削除]│
│#1231│××対応     │要確認(人対応)   │ticket/1231   │09/14 23:10│[詳細][削除]│
└──────────────────────────────────────────────────────────────┘
```

### 表示項目（キュータブ）
| 項目 | 内容 |
|---|---|
| 実行順序 | ドラッグ&ドロップで並べ替え可能（`waiting`状態の行のみ移動可。`running`より前には移動不可） |
| チケット番号 | Redmine上のチケットへのリンク（新規タブ） |
| タイトル | 登録時にRedmineから取得・保存した件名（キャッシュ）。Redmine停止中でも一覧は表示できる |
| 状態 | 待機中／実行中／中断要求中 |
| 実行中の進捗 | 実行中は再実装回数を併記（例：`実行中(2/3)`＝retryCount 2／retryLimit 3） |
| 実装AI／レビューAI | 個別指定時はモデル名、未指定時は「default（実際のデフォルト値）」と表示 |
| 登録者 | Windows認証のアカウント名（`DOMAIN\sato`形式でそのまま表示） |
| 操作 | `waiting`：削除／`running`：中断・詳細 |

### 表示項目（履歴タブ）
| 項目 | 内容 |
|---|---|
| チケット番号・タイトル | キュータブと同じ |
| 状態 | 完了（プッシュ済み）／要確認（人対応）／中断済み |
| ブランチ | 作成されたブランチ名（プッシュ済み・WIP退避済みのいずれも表示） |
| 終了日時 | `finishedAt` |
| 操作 | 詳細（ログ閲覧）・削除 |

### 操作
- **チケット追加**：チケット番号（必須）、実装AI／レビューAI（任意、未指定はデフォルト）を入力し追加。追加時にRedmineへ存在確認と件名取得を行う。同一チケット番号が`waiting`/`running`で既に存在する場合はエラー（履歴にある同じ番号の再登録は可能＝`needs_human`のチケットを人が確認後、再度AIに任せる導線となる）。
- **並べ替え**：`waiting`状態のチケットのみドラッグ&ドロップで順序変更可能。
- **キュー全体の一時停止／再開**：画面右上のトグルボタン。一時停止中はバナー表示（例：「キューは一時停止中です」）。
- **強制中断**：`running`状態の行にのみ表示。押下時に確認ダイアログを出す。押下後、実際に中断されるまでの間は状態を「中断要求中」と表示する（実行エンジンが最大5秒以内に検知して中断する）。
- **削除**：`running`以外のすべての状態で可能（`waiting`／履歴タブの`pushed`・`needs_human`・`canceled`）。`running`のチケットは中断してから削除する。押下時に確認ダイアログを出す。削除してもGitのブランチとRedmineのコメントは残る。

### 状態と表示色（提案）
| 状態 | 表示 | 色 |
|---|---|---|
| waiting | 待機中 | グレー |
| running | 実行中 | 青 |
| running＋中断要求あり | 中断要求中 | オレンジ（点滅なし） |
| needs_human | 要確認（人対応） | 赤 |
| pushed | 完了（プッシュ済み） | 緑 |
| canceled | 中断済み | オレンジ |

## 2. チケット詳細／ログ画面

### 目的
特定チケットの実行ログ（実装・レビュー・差し戻し・タイムアウト・エラー・中断・復旧の履歴）を時系列で確認する。

### レイアウト（イメージ）
```
┌──────────────────────────────────────────────────────────┐
│ ← 一覧に戻る   #1235 △△バグ修正   状態: 実行中(2/3)          │
│                ブランチ: ticket/1235              [強制中断]  │
├──────────────────────────────────────────────────────────┤
│ 18:05:01 [実装]    実装AIによる差分作成を開始…                │
│ 18:07:30 [レビュー] RESULT: FAIL - ○○の考慮漏れがあります     │
│ 18:07:31 [差し戻し] retryCount=1/3、指摘内容を実装AIへ渡します │
│ 18:09:10 [実装]    修正差分を作成…                           │
│ 18:10:40 [レビュー] RESULT: PASS                             │
│ 18:10:41 [プッシュ] ticket/1235 を origin へ push しました     │
└──────────────────────────────────────────────────────────┘
```

### 表示項目
| 項目 | 内容 |
|---|---|
| ヘッダ | チケット番号・タイトル・現在の状態（実行中は再実装回数）・ブランチ名・直近のエラー（`lastError`） |
| ログ一覧 | 時刻／フェーズ／内容。フェーズは 実装／レビュー／差し戻し／プッシュ／タイムアウト／エラー／中断／復旧 |

### 操作
- `running`状態の場合のみ「強制中断」ボタンを表示（一覧画面と同じ挙動）。
- ログは`logs/{チケットID}.jsonl`から取得し、追記順に表示する。

## 3. 設定画面

### 目的
デフォルトAIモデル・再実装上限回数・タイムアウトなど、`settings.json`の内容を確認・変更する。

### レイアウト（イメージ）
```
┌──────────────────────────────────────────────────────────┐
│ 設定                                                        │
├──────────────────────────────────────────────────────────┤
│ デフォルト実装AIモデル      [gpt-4o        v]                 │
│ デフォルトレビューAIモデル   [gpt-4o        v]                 │
│ 再実装ループの上限回数       [3   ]回                          │
│ 実装フェーズのタイムアウト   [30  ]分                          │
│ レビューフェーズのタイムアウト [10  ]分                         │
│                                              [保存]          │
├──────────────────────────────────────────────────────────┤
│ 参考情報（設定ファイルで管理・本画面からは変更不可）              │
│  Redmine URL: https://redmine.example.com                   │
│  対象リポジトリ: C:\repos\target-app（ベースブランチ: main）    │
└──────────────────────────────────────────────────────────┘
```

### 表示・編集項目
| 項目 | 編集可否 | 保存先 |
|---|---|---|
| デフォルト実装AIモデル | 可 | `settings.json` |
| デフォルトレビューAIモデル | 可 | `settings.json` |
| 再実装ループの上限回数 | 可（1以上の整数） | `settings.json` |
| 実装フェーズのタイムアウト（分） | 可（1以上の整数） | `settings.json` |
| レビューフェーズのタイムアウト（分） | 可（1以上の整数） | `settings.json` |
| Redmine URL／対象リポジトリ／ベースブランチ | 不可（参照表示のみ） | `config/config.json`（機微情報のため画面からの編集は不可） |

### 入力チェック
- 再実装上限回数・各タイムアウト：1以上の整数のみ許可。
- AIモデル：GitHub Copilot CLIが対応するモデル一覧から選択（自由入力は不可）。
- 変更は保存後に開始される処理から反映される（実行中のチケットには適用しない）。
